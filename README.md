# uwu-provider-german

Nuvio scraper providers for German streaming sites.

## Providers

| Provider | Site | Supports |
|----------|------|---------|
| Aniworld | aniworld.to | Anime (Sub/Dub), Movies |
| Serienstream | s.to | TV Shows |

## Install in Nuvio

**Settings → Plugins → Add Plugin**, paste:

```
https://raw.githubusercontent.com/VaniMoe/uwu-provider-german/main/manifest.json
```

## Supported Hosters

VOE · Streamtape · Vidoza · Doodstream · Vidmoly · Filemoon
